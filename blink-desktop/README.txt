Blink Desk Buddy (prototype 0.2)
================================

Start
-----
Double-click Blink.exe. No installer and no admin rights are needed.
Blink drops onto the top of your taskbar and says hi.
There is no window or taskbar button. Look for the small Blink face in the system tray
(click the ^ arrow near the clock if it is hidden).

On / off
--------
Click the Blink face in the system tray to turn Blink off or on (right-click it for the menu).
When Blink is off the icon is dimmed, the robot is gone and nothing is watched or animated;
Blink stays off after a restart until you turn it on again. Also: Ctrl+Alt+O, the first item
in the menu ("Blink is on"), typing "turn off" in the command box, or starting Blink.exe again (turns it on).

Keyboard shortcuts (work from any app)
--------------------------------------
Ctrl+Alt+O            Turn Blink on / off
Ctrl+Alt+B            Talk to Blink (command box)
Ctrl+Alt+Shift+B      Hide for 1 hour / show again
Ctrl+Alt+/            Show all shortcuts in a speech bubble

Actions               Ctrl+Alt+D dance     Ctrl+Alt+W wave      Ctrl+Alt+J jump
                      Ctrl+Alt+S spin      Ctrl+Alt+K joke      Ctrl+Alt+R stretch break
                      Ctrl+Alt+N nap / wake up
Moving                Ctrl+Alt+G come to my mouse pointer
                      Ctrl+Alt+F hide in a desktop file
Outfits               Ctrl+Alt+1 Bubblegum   2 Sunny   3 Mint Kitty   4 Lavender Bunny   5 Panda
                      Ctrl+Alt+6 Sprout      7 Classic 8 Snow Buddy   9 Sleepy Cap     0 random
Size                  Ctrl+Alt+=  bigger      Ctrl+Alt+-  smaller

If another app already uses one of these, Ctrl+Alt+/ marks it "taken by another app".

Mouse
-----
Click an empty spot on the desktop   Blink flies there
Click a file icon on the desktop     Blink goes to look at it, or dives into it and pops out later
Click Blink                          Poke (it giggles). Double-click: jump
Drag Blink and let go                Throw it (or let go gently up high and it floats there)

Tricks (Ctrl+Alt+B, then type)
------------------------------
catch the butterfly / catch the bird  One flutters in; Blink chases it, misses once, catches it and lets it go
go away / hide                        Hides for an hour (Ctrl+Alt+Shift+B brings it back sooner)
come back                             Wakes Blink up
Right-click Blink                    Menu: on/off, actions, outfits, roaming, size, activity, start with Windows, quit

Roaming
-------
Blink walks along the taskbar and sometimes flies around the desktop. It only flies over parts
of the screen where your desktop is visible, and heads back down if you open a window there.
Turn this off in the menu: "Roam around the desktop" and "Follow my clicks on the desktop".

Stays out of your way
---------------------
- Clicks pass through everywhere except Blink itself. It never takes keyboard focus
  (except while the command box is open).
- While you type, Blink fades, shrinks and parks in a corner. After 10 minutes away it naps.
- Outfits change by themselves now and then (menu > Auto outfit change). Sleepy Cap after 9 pm.

What Blink reads
----------------
Only coarse signals: where the mouse pointer is, whether the left button is pressed, which window
is under a point, seconds since your last input, and desktop icon names and positions.
It never reads what you type, file contents, or the screen.

Settings
--------
This copy is in portable mode (the file named "portable" is next to Blink.exe), so settings
are saved in the "data" folder here. Delete the "portable" file to save them in
%APPDATA%\Blink instead.

Uninstall
---------
Quit Blink from the menu, then delete this folder. If you turned on
"Start with Windows", turn it off first in the menu.
